# Dati — Campionato Broccoli

Firebase Realtime Database, Auth e Storage (configurazione nel file `index.html` e nella console Firebase).

## Regole
- Modifiche solo additive e reversibili.
- Backup verificato prima di ogni variazione (export del Realtime Database dalla console Firebase (nessuno script nel repository)).
- Mai cancellazioni o aggiornamenti di massa sui dati esistenti.
